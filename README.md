## Etapa 6: Date de la un mock API
Lista este servită de `json-server` din fișierul `db.json`. Aplicația o cere la încărcare (fetch) și afișează o stare de așteptare (loading) și o stare de eroare.

npm run dev # terminalul 1, http://localhost:5173
npm run api # terminalul 2, http://localhost:3001

## Etapa 8: Navigare și stilizare pe componente
Aplicația a fost împărțită în mai multe pagini folosind React Router: pagina principală cu lista de produse (`/`), pagina de detaliu (`/produse/:id`), pagina de prezentare (`/despre`) și pagina 404 pentru adrese inexistente (`*`). Stilurile componentelor au fost mutate în fișiere CSS Modules (`*.module.css`), iar `index.css` păstrează doar variabilele de culoare și clasele comune.
